# Introduction

This handbook defines Talenta's standard interview process. Every recruiter and hiring manager must follow these guidelines to ensure fair, consistent, and objective candidate evaluations.

---

# INT-101 Interview Process

Every candidate follows the same interview workflow.

Stage 1
Application Screening

↓

Stage 2
HR Interview

↓

Stage 3
Technical Interview

↓

Stage 4
Hiring Decision

↓

Stage 5

---

# INT-102 HR Interview

Purpose

The HR interview evaluates the candidate's communication skills, motivation, and cultural fit.

Topics include:

- Career goals
- Previous work experience
- Team collaboration
- Communication skills
- Salary expectations
- Availability

Typical duration:
30–45 minutes.

---

# INT-103 Technical Interview

Purpose

The technical interview evaluates the candidate's professional knowledge required for the position.

Interviewers should evaluate:

- Technical skills
- Problem-solving ability
- Practical experience
- Knowledge of required tools
- Project experience

Examples:

Software Engineer

- Python
- Java
- SQL
- Git
- REST APIs

Cybersecurity Engineer

- Linux
- Networking
- SIEM
- Firewalls
- Incident Response

Data Analyst

- SQL
- Power BI
- Excel
- Statistics
- Data Visualization

---

# INT-104 Behavioral Interview

Behavioral interviews measure how candidates react in real workplace situations.

Suggested questions:

- Describe a difficult project.
- Tell us about a conflict you solved.
- Describe a leadership experience.
- Explain a challenging deadline.

Interviewers should evaluate:

- Communication
- Leadership
- Adaptability
- Teamwork
- Decision making

---

# INT-105 Candidate Evaluation Rubric

Candidates are evaluated across five dimensions.

Technical Skills
40%

Experience
20%

Communication
15%

Problem Solving
15%

Culture Fit
10%

Final score = weighted average.

---

# INT-106 Interview Recommendation Levels

Strong Hire

Candidate exceeds expectations.

Hire

Candidate satisfies all requirements.

Borderline

Requires HR discussion.

No Hire

Candidate does not meet expectations.

---

# INT-107 Interview Red Flags

Recruiters should pay attention to:

- Inconsistent employment history
- Inability to explain previous projects
- Poor communication
- Lack of required technical skills
- Unprofessional behavior

Red flags should always be documented in recruiter notes.

---

# INT-108 Interview Feedback

Interview feedback should include:

Candidate strengths

Areas for improvement

Technical observations

Behavioral observations

Final recommendation

Feedback must remain objective and evidence-based.

---

# INT-109 Interview Decision Rules

A candidate should not receive a hiring recommendation unless:

- All interview stages are completed.
- Every interviewer submits feedback.
- Evaluation scores are recorded.

Missing evaluations require manual HR review.
